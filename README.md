# 📦 Складской робот

**2D-головоломка на Unity**

Управляйте складским роботом, доставляйте коробки в зону выхода и избегайте опасных зон. Три уровня с нарастающей сложностью, сохранение прогресса и рекордов.

---

## 🎮 Об игре

**Складской робот** — учебный проект, разработанный в рамках производственной практики по созданию игрового продукта. Игра реализует механику доставки грузов с особым правилом: робот может нести только одну коробку за раз, и зачёт происходит только при доставке в зону выхода.

### 🎯 Цель
Перенести все коробки в зону выхода по одной, избегая опасных зон и сохраняя жизни.

### 🕹️ Управление
- **WASD** или **стрелки** — движение робота
- **Esc** — пауза
- Экранная панель — движение на мобильных устройствах

### 📊 Уровни сложности

| Уровень | Коробок | Опасностей | Дверь выхода |
|---------|---------|------------|--------------|
| 1       | 3       | 2          | Правый верх  |
| 2       | 5       | 4          | Левый верх   |
| 3       | 6       | 6          | Центр низ    |

---

## ✨ Особенности

- **Три уровня** с ростом сложности и различными позициями объектов
- **Сохранение прогресса** — открытые уровни и рекорды сохраняются между сессиями
- **Настройки громкости** — регулировка звука с сохранением
- **Автоматическая пауза** при потере фокуса окна
- **Особое правило** — доставка по одному объекту с зачётом только в зоне выхода
- **Адаптивный интерфейс** — поддержка соотношений 16:9, 18:9, 4:3
- **Профилирование** — оптимизация через кэширование `FindObjectsByType`

## 🚀 Как запустить

### Требования
- **Unity 6000.6.2f1** или новее
- **Visual Studio Code** (опционально, для редактирования кода)

### Установка
1. Клонируйте репозиторий.

2. Откройте проект в Unity:
   - Запустите Unity Hub
   - Нажмите **Open** → выберите папку проекта
   - Дождитесь импорта ассетов

3. Откройте сцену:
   - В окне **Project** перейдите в `Assets/Scenes`
   - Дважды кликните по `Main.unity`

4. Нажмите **Play** для запуска игры

## 📝 Ключевые компоненты

### GameManager
Центральный контроллер игры. Управляет состоянием, правилами варианта, переходами между экранами.

### SaveService
Статический класс для работы с `PlayerPrefs`. Сохраняет открытые уровни, рекорды и громкость.

### VisualTheme
Система темизации с оптимизацией через кэширование результатов `FindObjectsByType`.

### HUDView
Компонент интерфейса, отображающий прогресс, подсказки и результаты.

## 📈 Производительность

Проект прошёл оптимизацию с использованием Unity Profiler:
- **До:** `FindObjectsByType` вызывался при каждом применении темы
- **После:** Результаты кэшируются, сброс кэша только при изменении сцены
- **Результат:** Снижение нагрузки на CPU в кадрах запуска уровня
