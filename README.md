# «Кристальный маршрут»: основа оформления УП.ПМ.13

Откройте эту папку через Unity Hub в Unity 6000.6.2f1.

1. Исходная сцена — `Assets/Scenes/Main.unity`: нейтральное оформление и готовая механика.
2. Сохраните свою копию через File → Save As как `Assets/Scenes/Student.unity`.
3. Выберите GameManager и задайте Variant Number: 0 — отдельная демонстрация; 1–30 — профили предметных областей из `Assets/profiles.json`.
4. Нажмите Play, затем кнопку «Играть». Управляйте WASD, стрелками или экранными кнопками.
5. Для паузы используйте Escape или кнопку «Пауза». Для сброса — кнопку «Заново» на результате; для новой попытки можно вернуться в меню.

В демонстрационном архиве дополнительно есть `Assets/Scenes/Demonstration.unity` с оформленной палитрой. Открывайте её для сверки после самостоятельного изменения.

Объекты сцены сохраняются до запуска. `GameBootstrap` не создаёт уровень; интерфейс использует единственный Canvas. Палитра задаётся на GameManager в VisualTheme, связи экранов и HUD — на Canvas. Код и точные действия объяснены в методичке.

При сдаче проекта приложите ссылку на его репозиторий.
